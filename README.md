# carbon-pro
A high-performance, resource-efficient WordPress theme inspired by the IBM Carbon Design System.

## Description
Carbon Pro is a lightweight, high-performance WordPress theme that follows the IBM Carbon Design System. It is designed to be resource-efficient while providing a clean, technical aesthetic.

## Features
- IBM Carbon Design System aesthetic
- IBM Plex Sans typography
- High performance and low resource usage
- Support for Posts and Pages
- Static Front Page support with Hero section
- Custom 404 Error Page
- Custom Navigation Menu support
- Responsive design

## Installation
1. Zip the 'carbon-pro' folder. **We have included a carbon-pro.zip folder you can easily add to your WP Admin.**
2. Upload to WordPress via Appearance > Themes > Add New.
3. Activate.
4. Go to Settings > Reading to set your static front page.
5. Go to Appearance > Menus to set up your primary navigation.
